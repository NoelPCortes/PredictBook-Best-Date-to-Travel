# Frontend

The frontend uses React with TypeScript and Vite.

The [project README](../README.md) reserves these shared directories:

- `frontend/src/api/`: shared API client.
- `frontend/src/components/`: shared UI components.
- `frontend/src/pages/`: pages.
- `frontend/src/types/`: shared TypeScript types.

See [coding standards](../CODING_STANDARDS.md) for the feature folder rules and the [UI style guide](../frontend/UI_STYLE_GUIDE.md) for interface requirements.
